# Poise Click

这是一个手机优先的点击即用版本，适合在没有 `Apple Developer` 账号、又希望 `iPhone 点开即用并添加到主屏幕` 的情况下使用。

## 使用方式

1. 用 `Safari` 打开网页链接
2. 点击底部“分享”
3. 选择“添加到主屏幕”
4. 以后从主屏幕打开，会更像一个独立 App

## 当前定位

- 保留打卡、进度、复盘、周总结
- 每个训练项都附带自查要点、官方知识来源和应用内跟练图示
- 首页提供“晨间全套”入口，能按顺序带你做完当天体态四件套
- 设置页提供 iPhone/iPad 日历提醒订阅入口，默认含 2 次全套 + 3 次小纠正
- 数据保存在当前浏览器本地
- 首次在线打开后，主要页面资源会缓存到本机，之后断网也能继续打开和记录
- 不依赖 App Store、TestFlight、开发者账号
- 当前版本优先解决“可立即打开和使用”
